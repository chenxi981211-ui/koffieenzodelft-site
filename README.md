# Koffie & Zo — Delft

The website for Koffie & Zo, a coffee shop, lunch room and vintage store at
Peperstraat 17 in Delft.

A static site: two pages, no build step. `index.html` is the home page,
`menu.html` is the digital menu, and `data/menu.json` holds the whole card —
edit that file to change what's on the menu.

Live at <https://chenxi981211-ui.github.io/koffieenzodelft-site/>

Run it locally with any static server, for example:

```bash
python3 -m http.server 4321
```
